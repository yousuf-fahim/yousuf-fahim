Enjoying the game? Share this with friends and let them make the next move!

#### Rules

- Standard chess rules apply
- You can't move twice in a row - wait for someone else to play
- Only valid moves are accepted
- Pawns auto-promote to Queen

#### How it works

When you click on a link and submit a new issue with the desired move, a GitHub action is triggered, which in turn runs a small python script that performs the specified movement, updates this README file and commits the changes.

Have you spotted a bug? Something missing? Feel free to reach out via an [issue](https://github.com/yousuf-fahim/yousuf-fahim/issues) and I will try to fix it as soon as possible :D
